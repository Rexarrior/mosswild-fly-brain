# Mosswild — мозг мухи управляет жуками в Unreal

Две колонии инсектоидов в небольшом лесном биоме: еда, вода, территория,
потомство и игрок, который может вмешаться. Моторное управление подключено к
[SiliconFly](https://github.com/dawsonamf/siliconfly) и
[FlyBrainEngine](https://github.com/mehrantsi/flyBrain) через локальный сервис.
Есть также простой реактивный контроллер для сравнения.

![Биом Mosswild](Docs/Mosswild.jpg)

Это игровой эксперимент, а не воспроизведение поведения настоящей мухи.
Потребности, контакты, размножение и правила мира задаёт игра. В режиме с
планировщиком игра выбирает цели; в сенсорном режиме модель получает восемь
одновременных сигналов и выдаёт поворот и скорость. Подробная история —
[черновик статьи](Docs/Articles/Habr-fly-brain.md).

## Требования и запуск

Проверено на **macOS, Apple M2 Pro, 32 GB RAM, Unreal Engine 5.8.2**.
Нейронные адаптеры используют Metal; Windows/Linux для них здесь не поддержаны.
Нужны полный Xcode с Metal Toolchain, Swift, Cargo, Python 3 и
[uv](https://docs.astral.sh/uv/). Сторонние ассеты из магазина не нужны.
Unreal Engine устанавливается отдельно и в репозиторий не входит.

Из корня checkout:

```sh
python3 Scripts/ue.py doctor
python3 Scripts/BrainLab/lab.py setup
python3 Scripts/BrainLab/lab.py probe
python3 Scripts/ue.py build       # Unreal Editor должен быть закрыт
python3 Scripts/BrainLab/lab.py start
python3 Scripts/ue.py open
```

Редактор открывает **Mosswild**. Нажми Play и щёлкни в игровом окне.
Можно открыть `RPGPrototype.uproject` вручную. Имя файла и C++-модуля сохранено
ради совместимости сериализованных классов; исходная RPG-долина удалена.
Другая установка движка задаётся через `UE_ROOT`; по умолчанию
`/Users/Shared/Epic Games/UE_5.8`.

`setup` скачивает закреплённые ревизии движков и данные, проверяет хеши и
собирает адаптеры. Они и окружение Python находятся в `Saved/BrainLab/` и
занимают примерно 1,3 GB. Первый запуск требует интернета. Полные коннектомы
и журналы прогонов не включены в Git; компактные результаты есть в `Docs/`.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки, Shift, Space | Ходьба, бег, прыжок |
| Колесо / + / − | Масштаб камеры |
| O, 1 / 2 | Обзор / слежение за игроком, камеры колоний |
| M / Tab | Карта биома |
| N | Планировщик / одновременные раздражители; сбрасывает колонии |
| H | Социальные поправки в режиме планировщика |
| F | Удар; колонии отвечают на вторжение |
| G | Засуха / восстановление |
| B | Сброс с отключением / включением связей мозга |
| R, P | Сброс, пауза |
| L | Mosswild ↔ исходная лаборатория Insectarium |
| Esc, Shift + F1 | Завершить PIE, освободить мышь |

При потере сервиса NPC останавливаются, HUD показывает причину.
Сервис слушает только `127.0.0.1:18765`.

```sh
python3 Scripts/BrainLab/lab.py status
python3 Scripts/BrainLab/lab.py stop
```

## Разработка и проверки

`Source/RPGPrototype/Insect*` — нейронный интерфейс, жуки и экология;
`RPGCharacter`, `RPGHUD`, `RPGGameMode` — игрок-наблюдатель и интерфейс лаборатории.
`Scripts/BrainLab/` — сервис, адаптеры и эксперименты;
`Content/Python/` — построение сцен и проверки через Unreal API.

```sh
python3 Scripts/ue.py bootstrap   # создаёт только отсутствующие карты с жуками
python3 Scripts/ue.py smoke       # требует запущенного сервиса; итог асинхронный
```

Отчёт smoke: `Saved/BrainLab/biome-smoke.json`, поля `status: completed` и
`success: true`. Проверяются обе модели, вода, пища, доставка, бой и другие
механики в PIE. Map Check должен возвращать 0 ошибок.
Перед native-сборкой закрывай редактор, сохраняй пользовательские карты.
Не меняй `.uasset` и `.umap` вручную. Python-автоматизация ограничена loopback,
порты 6776/6777; wrapper проверяет путь проекта.

Некоторые стартовые `UE::UnifiedErrorTest` в установленном движке пишут
`LogAutomationTest: Error: Condition failed` до загрузки карты. Это не результат
smoke-проверки; новые ошибки во время игры требуют отдельной проверки.

Ревизии и происхождение внешних моделей записаны в скриптах setup и
[документации адаптеров](Docs/BrainLab.md). Их лицензии и условия данных
сохраняются в скачанных upstream-репозиториях; краткая сводка —
[THIRD_PARTY.md](THIRD_PARTY.md).
